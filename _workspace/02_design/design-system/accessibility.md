# Design System — 접근성 하한

## 6. 접근성 하한 (협상 불가 수치)

- 텍스트 4.5:1 (18.66px bold·24px+ 는 3:1) / 비텍스트(아이콘·보더·포커스 링·스트립 그래프 선) 3:1 — WCAG 2.2 AA.
- 포커스 링: `2px solid primary` + 2px offset, 모든 인터랙티브 요소. primary vs surface ≈5.6:1 ≥ 3:1.
- 최소 타깃 24×24px(WCAG 2.5.8), 스트립 스크럽 핸들·구간 행은 32px 이상 권장(태블릿 터치 최소 대응).
- 색 단독 상태 전달 금지(1.4.1) — §1 3중 인코딩·§2 배지 채널 순서가 구현 계약이다.
