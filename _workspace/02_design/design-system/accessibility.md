# Design System — 접근성 하한

## 6. 접근성 하한 (협상 불가 수치)

- 텍스트 4.5:1 (18.66px bold·24px+ 는 3:1) / 비텍스트(아이콘·보더·포커스 링·스트립 그래프 선) 3:1 — WCAG 2.2 AA.
- 포커스 링: `2px solid primary` + 2px offset, 모든 인터랙티브 요소. primary vs surface ≈5.6:1 ≥ 3:1.
- 최소 타깃 24×24px(WCAG 2.5.8), 스트립 스크럽 핸들·구간 행은 32px 이상 권장(태블릿 터치 최소 대응).
- 색 단독 상태 전달 금지(1.4.1) — §1 3중 인코딩·§2 배지 채널 순서가 구현 계약이다.
- **현재 구간 하이라이트**(FEAT-019)도 색 단독이 아니다: 3D 안에서 색(`primary` 면) + 형태(윤곽선)
  두 채널이고, **텍스트 채널은 3D 밖에 이미 있다** — 같은 구간이 구간 목록에서 `aria-selected`로
  강조된 행이고 스트립의 `aria-valuetext`("슬로프 상승 중, 12/132")가 같은 사실을 읽어 준다. 3D
  캔버스 자체는 보조기술 경로가 아니며(§skip-link가 목록으로 간다) 하이라이트에 대응하는 새 ARIA
  표면을 만들지 않는다 — 같은 사실을 두 곳에서 통지하면 스크린리더에 중복이 들린다.
