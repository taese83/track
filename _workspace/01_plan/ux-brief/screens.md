# UX Brief — 화면 인벤토리·상태

## Screen Inventory (단일 화면의 상태 분기)
| 상태 | 목적 | 핵심 구성 |
|---|---|---|
| 입력 대기 | URL 붙여넣기 유도 | 입력창, placeholder 예시, "붙여넣으면 바로 보입니다" 안내 |
| 로딩(파싱 중) | 대기 불안 해소 | 진행 인디케이터, 지연 임계값(ASSUMPTION-007) 초과 시 "시간이 걸리고 있어요" 메시지 |
| 3D 표시(성공) | 형상 확인 + 구간 판단 | 3D 캔버스, 하단 프로파일 스트립, 시점 전환·회전·줌 컨트롤, 근거등급 범례, 출처 링크(원본 편집기, REQ-F-019). 하위 배지: 미지원 피스 플레이스홀더+"미지원: {타입명}" 라벨(REQ-F-008), 대형 트랙 시 "대형 트랙: 일부 최적화 적용" 안내(REQ-F-012) |
| 부분 실패(복원 실패·비폐곡선) | 신뢰 붕괴 없이 판단 지속 | 경고 배너 상시 노출, 복원된 조각만 렌더, 끊긴 지점 강조색·아이콘 표시 |
| 완전 실패(URL/트랙 없음/편집기 응답 실패/파싱 실패) | 원인 파악 후 재시도 | 원인별 문구 분리("유효하지 않은 링크입니다" / "트랙을 찾을 수 없습니다" / 응답 실패 시 재시도 버튼 / 파싱 실패 시 접이식 디버그 영역에 원본 응답 일부) |
| WebGL 미지원(감지) | 3D 렌더링이 원천적으로 불가한 환경에서도 판단 수단 유지 | 진입 즉시 WebGL 컨텍스트 생성 가능 여부 감지 → 실패 시 3D 캔버스를 그리지 않고 안내 배너 노출("이 브라우저/기기는 3D 렌더링을 지원하지 않습니다") + 아래 "텍스트 구간 목록"을 기본 뷰로 자동 전환(토글 아님, 대체 화면). 지원 브라우저 안내 링크 병기 |


## Key Screen Elements Requiring FEAT (Must TC 조작 수단)

아래 두 요소는 Screen Inventory의 "3D 표시(성공)" 상태 안에서 Must 등급 Test Case(예: 구간별 고저차 확인, 스크린리더 대체 확인)를 실제로 수행하게 하는 조작 수단이다. 현재 REQ/FEAT의 명시적 소유가 없으므로 feature-planner가 FEAT를 만들 수 있도록 목적·최소 동작·정보 위계상 위치를 아래에 등재한다.

| Element | Purpose | Minimal behavior (MVP) | 정보 위계상 위치 | 관련 Must TC 성격 |
|---|---|---|---|---|
| 하단 프로파일 스트립 | 전체 트랙의 거리축+고저차를 한눈에 보여주는 미니맵 겸 보조 내비게이션 | 클릭/드래그 시 3D 카메라가 해당 지점으로 부드럽게 이동(스크럽), 현재 3D 카메라 위치를 스트립 위 마커로 상시 표시 | "3D 표시" 화면 Primary ③(현재 보는 구간의 고저차·각도) 판단을 지원하는 상시 노출 보조 패널(Secondary 영역 하단 고정) | 구간별 고저차·상승/하강 판단, 특정 지점으로의 이동 조작 |
| 텍스트 구간 목록 | 스크린리더·저시력 사용자를 위한 3D 뷰의 1차 대체 정보원. 세그먼트별 유형(슬로프/뱅크/레인체인지/웨이브)·방향·각도·거리를 표로 제공. WebGL 미지원 시에는 대체 화면 본체로도 재사용 | 토글로 표시/숨김(3D 표시 상태), WebGL 미지원 시에는 기본 노출(토글 없음). 각 행 클릭/Enter 시 해당 구간으로 포커스·카메라 이동(프로파일 스트립과 동일한 스크럽 동작 공유) | "3D 표시" 화면의 접근성 대체 표현(Secondary 영역, 키보드 포커스 진입점) / "WebGL 미지원" 화면의 Primary 콘텐츠 | 스크린리더로 세그먼트별 상승/하강·각도 판단, 마우스 없는 전체 탐색 |


## Information Hierarchy per Screen
| Screen | Primary (1~3, 우선순위순) | Secondary | Density | Empty state | Error state | No-permission |
|---|---|---|---|---|---|---|
| 입력 대기 | ① 무엇을 붙여넣는지 | 예시 링크, 지원 형식 | 낮음 | "URL을 붙여넣으면 트랙이 나타납니다" | — | N/A(계정 없음) |
| 로딩 | ① 진행 중임을 인지 | 예상 소요·조각 수 | 낮음 | — | 잠정(ASSUMPTION-007) 임계값 초과 시 "시간이 걸리고 있어요" | N/A |
| 3D 표시 | ① 형상이 도면과 일치 ② 상승/하강 위치 ③ 현재 보는 구간의 고저차·각도 | 전체 거리(편집기 `l` 단위 합, unknown — 절대 미터 미표기)·총 피스 수(REQ-F-016), 레인체인지 위치, 근거등급(실측/추정/미확인) 범례, 회전/줌 힌트 | 중간(캔버스 몰입 우선, 컨트롤은 최소 UI) | N/A | — | N/A |
| 부분 실패 | ① 복원 안 된 구간이 있다는 사실 ② 어디까지가 신뢰 가능한 렌더인지 | 원인 요약(끝점 매칭 실패) | 낮음 | — | 배너 텍스트: "일부 구간의 순서를 확정하지 못해 해당 구간은 회색으로 표시됩니다" | N/A |
| 완전 실패 | ① 실패했다는 사실 ② 다음 행동(재시도) | 원인 한 줄 | 낮음 | — | "트랙을 불러오지 못했습니다. URL을 확인해 주세요" | N/A |
| WebGL 미지원 | ① 3D를 볼 수 없다는 사실 ② 그래도 트랙 정보를 판단할 대안이 있다는 것 | 지원 브라우저 안내 링크 | 낮음 | — | "이 브라우저는 3D 렌더링을 지원하지 않습니다. 대신 텍스트 구간 목록으로 트랙 정보를 확인하세요" + 텍스트 구간 목록 자동 노출 | N/A |


## Critical States & Annotation Intent
| Surface/annotation | 상태 | User intent | Error prevention | Verification |
|---|---|---|---|---|
| 3D 뷰 / 복원 실패(비폐곡선) | edge | 트랙 전체로 착각하지 않게 | 경고 배너 상시 노출 + 실패 구간 회색·점선 처리 | 실제 실패 데이터셋으로 QA |
| 고저차 그래프 / 추정치 | normal | 실측 아님을 항상 인지 | "추정" 라벨 고정 노출, 축 단위 대신 "상대 스케일" 표기 | 실측 트랙 대조 리뷰 |
| 추종 시점 / 자동재생 중 | normal | 주행 시뮬레이션이 아님을 인지 | "배속" 대신 "탐색 속도" 용어, 실제 주행 시간 미표기 | 카피 리뷰 |
| 3D 뷰 / 미지원 피스 타입 | edge | 조용히 생략된 게 아님을 인지 | 와이어프레임 플레이스홀더 + "미지원: {타입명}" 라벨 상시 노출(REQ-F-008) | 미지원 타입 주입 테스트 데이터로 확인 |
| 3D 뷰 / 대형 트랙 성능 완화 | edge | fps 저하가 아니라 의도된 최적화임을 인지 | "대형 트랙: 일부 최적화 적용" 배지 상시 노출(REQ-F-012) | 확장 데이터로 fps·배지 노출 측정 |
| 진입 화면 / WebGL 미지원 | edge | 3D를 못 봐도 판단을 포기하지 않게 | WebGL 컨텍스트 생성 실패 즉시 감지 → 3D 캔버스를 그리지 않고 텍스트 구간 목록으로 자동 폴백(수동 토글 불필요) + 안내 배너 | WebGL 비활성화 브라우저/헤드리스·구형 기기 환경으로 QA |
