# UX Brief — UX 결정·체크·접근성

## Key UX Decisions (trade-off 포함)

1. **추종 시점의 형태·조작 (결정 완료)**: 기본값을 "스크럽(사용자가 프로파일 스트립을 드래그/클릭해 구간 이동)"으로 **확정**하고, 자동 재생은 옵션(속도 조절·즉시 일시정지)으로 둔다. (과거 초안의 ND1 "스크럽 vs 자동재생 기본값"은 이 결정으로 해소되었다.)
   - Trade-off: 자동 재생은 몰입감은 크지만 멀미 유발과 "필요한 만큼 오래 보기"가 어려움. 스크럽은 통제감은 크지만 초반 방향 감각 파악이 느림.
   - 멀미 대책: 급회전 시 시야각 제한, 카메라는 근접 3인칭(1인칭 금지), easing으로 급정지/급가속 회피.

2. **장거리 트랙 탐색 전략**: 항상 보이는 하단 "측면 프로파일 스트립"(거리축 + 고저차)을 미니맵 겸 네비게이터로 사용. 클릭 시 3D 카메라가 해당 지점으로 부드럽게 이동.
   - Trade-off: 상시 노출 패널은 캔버스 면적을 줄이지만, 없으면 3D 공간에서 방향 감각을 잃기 쉬움(전체 거리 190.84, 편집기 `l` 단위, unknown — B-001 미해결이라도 짧은 트랙으로 볼 수 없는 규모).
   - 대안(휠 확대만으로 탐색)은 기각: 회전된 3D에서 "지금 어느 지점인지" 인지 부담이 큼(절대 거리(m) 단위는 B-001 미해결로 화면에 표기하지 않는다 — R2).

3. **고저차 표현과 오해 방지**: 슬로프 낙차·뱅크 전이곡선 등 값마다 실측/추정/미확인 3단계 근거등급 배지(REQ-F-013)를 3D 뷰와 프로파일 그래프 양쪽에 상시 노출. 시각적 과장(수직 스케일 확대) 적용 여부는 NEEDS_DECISION.
   - Trade-off: 과장 없으면 현(chord) 40도 경사도 밋밋해 보여 판단이 어려움. 과장하면 "실측처럼 보인다"는 기존 오해 위험이 커짐 → 과장 시 반드시 축에 "상대 스케일(실측 아님)" 명시.

4. **부분 실패(비폐곡선)의 노출 방식**: 완전 차단 대신 복원된 조각만 렌더 + 상시 경고 배너.
   - Trade-off: 부분 렌더는 판단을 계속 가능하게 하지만, 배너를 놓치면 불완전한 트랙을 완전한 것으로 오인할 위험 → 실패 구간을 회색/점선으로 시각적으로도 구분.

5. **색 대비 상승/하강 이중 인코딩**: 색(초록/주황) + 형태(위/아래 화살표 아이콘) + 텍스트 라벨("상승 5%") 3중 인코딩.
   - Trade-off: 정보 밀도가 늘지만 색각 이상 사용자를 배제하지 않기 위한 필수 비용.


## UX Check
- **첫눈에 알 수 있어야 하는 것**: 도면과 형상이 일치한다는 것, 오르막/내리막 위치(색+형태+라벨 3중 인코딩으로). 전체 거리·총 피스 수는 헤드라인 수치로 세우지 않고 Secondary 영역에 등급 배지(unknown)와 함께 후순위 노출한다(B-001 미해결·R2).
- **다음 행동이 보이는가**: 최초 진입 시 "드래그로 회전, 하단 그래프를 눌러 구간 이동" 1회성 힌트 필요 — 컨트롤 존재 자체가 캔버스만으로는 발견되지 않음(affordance 부족)
- **실수하거나 오해할 지점**: (기존) 고저차가 실측처럼 보임 / 3D가 주행 시뮬레이션이라는 오해 / (추가) 부분 렌더를 완전한 트랙으로 착각 / 재생 속도가 실제 주행 속도를 의미한다는 오해 / 전체 거리 수치를 절대 미터로 오인
- **먼저 정할 방향**: 고저차 시각 과장 배율 적용 여부, 다크/라이트 기본 배경 — 추종 시점 기본 모드는 스크럽(수동)으로 결정 완료(Key UX Decision 1), 더 이상 미결 아님
- **prototype·Phase 2에서 확인할 것**: 실사용자가 형상 일치를 첫눈에 확인하는지(임계 시간은 잠정, 확정 안 함), 자동재생 사용 시 멀미 보고 여부, 색맹 시뮬레이터로 상승/하강 구분 가능한지, 모바일에서 링크 수신→1차 확인 흐름의 실사용성, WebGL 미지원 환경에서 텍스트 구간 목록만으로 판단이 가능한지


## Accessibility
- **키보드 조작**: 화살표키로 회전, +/-로 줌, Tab으로 프로파일 스트립의 구간 포인트 순회, Enter로 해당 지점 점프(마우스 없이 전체 탐색 가능해야 함)
- **대체 표현**: 3D 캔버스 옆/아래에 "텍스트 구간 목록" 토글 제공 — 세그먼트별 유형(슬로프/뱅크/레인체인지/웨이브), 방향(상승/하강), 각도, 거리를 표로 나열. 스크린리더·저시력 사용자의 1차 정보원.
- **색 대책**: 상승=초록+위쪽 화살표 아이콘+텍스트, 하강=주황+아래쪽 화살표 아이콘+텍스트, 뱅크=기울어진 사각형 아이콘, 레인체인지=화살표 갈래 아이콘 — 색만으로 구분되는 요소를 두지 않는다.
