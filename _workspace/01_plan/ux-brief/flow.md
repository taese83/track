# UX Brief — 사용자 플로우·내비·인터랙션

## User Flow
```
① 진입(URL 입력 대기) → 확인: 여기에 무엇을 붙여넣어야 하는지, 형식 예시
② URL 붙여넣기 → 파싱/로딩 → 확인: 진행 중임(끊긴 게 아님), 실패 시 즉시 알 수 있는지
③ 3D 렌더링(전체 조망) → 확인: 도면과 형상이 같은가(첫눈에), 어디가 오르막/내리막인가
④ 탐색(회전·줌·구간 확대·추종 시점) → 확인: 특정 구간의 고저차, 연속 코너, 레인체인지 지점
⑤ 판단(세팅·전략 결정) → 필요시 ①로 복귀(다른 트랙 재붙여넣기)
```
저장이 없으므로 ⑤→①은 "다른 트랙 보기" 진입점이 상단에 항상 고정돼 있어야 한다.


## Navigation Structure
- 단일 화면이라 별도 내비게이션 트리 없음. 상단바에 "다른 트랙 보기(URL 재입력)" 진입점을 항상 고정 노출.
- 하단 프로파일 스트립이 보조 내비게이션 역할 겸임(구간 개요 + 클릭 이동) — 별도 사이드바 불필요.


## Key Interaction Patterns
- 프로파일 스트립 클릭/드래그: 구간 스크럽 이동(drill-down과 동일 개념)
- 3D 캔버스: orbit(드래그 회전) + 휠 줌, 더블클릭 시 해당 지점으로 확대
- 시점 전환 토글: 전체 조망 ↔ 추종 시점, 전환 시 카메라 이동은 즉시 컷 대신 부드러운 전환(방향 감각 유지)
- 재생 컨트롤: 재생/일시정지/속도 슬라이더 — "배속" 대신 "탐색 속도"로 표기(주행 시뮬레이션 오해 방지)
