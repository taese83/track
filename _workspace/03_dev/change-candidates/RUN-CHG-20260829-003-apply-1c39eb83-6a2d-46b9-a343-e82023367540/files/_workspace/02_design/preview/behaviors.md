범례: **PASS** = 프로토타입에서 Then(관찰 가능한 결과)을 실제로 재현·확인 가능.
**PASS(근사)** = 관찰 가능한 결과를 근사 구현(공식·수치는 실제 적용하되 3D 엔진/정밀 계측 없이 확인)으로 재현.
**N/A(사유)** = 본질적으로 구현/QA 단계 몫(실 네트워크·실 3D 엔진 수치 정밀도·성능 측정)이라 프로토타입에서 검증 불가.

프로토타입에서 조작하는 방법 공통: `preview/index.html`을 열고 좌하단 "프로토타입 전용 상태 전환" 패널

`ZGAP`(Z 폐합 실패) · `NOSTART`(START 없음) · `MULTI`(START 2개+) · `LARGE`(320피스) ·
